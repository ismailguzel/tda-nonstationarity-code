# Diagnosing the causes of non-stationarity with topological feature engineering

Code, data pipeline, run logs and results of the paper

> İ. Güzel and C. Yozgatlıgil, *Diagnosing the causes of non-stationarity with topological
> feature engineering*, submitted to the Hacettepe Journal of Mathematics and Statistics.

The paper casts the diagnosis of non-stationarity as multi-label detection — one binary
detector per cause: stochastic trend, volatility, linear trend, trend shift, mean shift,
variance shift, point anomaly, collective anomaly — and compares a set of 90 topological
features (TDA-90) with statistical feature sets when several causes act on one series.
Every number, table and figure of the paper can be regenerated from this repository.

## The experiment in brief

- **Data.** 72 classes — the stationary class and every combination of the eight causes that
  the generator [betise](https://pypi.org/project/betise/) 0.6.0 lists with at most one
  structural break and at most one anomaly per series — 500 series each, length 500
  (36 000 series). A series' *level* is the number of causes it carries (0-5).
- **Task.** Eight binary detectors, one per cause, each trained on all levels at once and
  scored separately at each level.
- **Features.** TDA-90 (90 features): Rips persistence of delay-embedded sliding windows,
  windowed sublevel persistence and sublevel persistence of the whole series. Compared with
  TSFresh-774, catch22 and MiniRocket, alone, added to TSFresh-774, and at an equal budget
  of 100 features.
- **Classifiers and inference.** Logistic regression and histogram gradient boosting, both
  class-weighted; MiniRocket with its ridge classifier; one stratified 5-fold
  cross-validation (seed 42); balanced accuracy and ROC AUC; Nadeau–Bengio corrected
  resampled t-tests. The hypotheses H1-H11 are those of Appendix B of the paper.

## Reproducing

```bash
python -m venv .venv && . .venv/bin/activate          # Python 3.11
pip install -r environment/requirements.txt
PAPER_PYTHON=$(which python) MODELS=lr bash experiments/run_all.sh smoke 10   # every step, minutes
PAPER_PYTHON=$(which python) bash experiments/run_all.sh paper                # the paper's numbers
python figures/make_figures.py                                               # figures and LaTeX tables
```

The full run takes about 10 hours on 12 cores, most of it MiniRocket. Data go to
`data/<tag>/`, outputs to `runs/<tag>/` (both git-ignored); `results/paper/` is the output
of the paper's run. Each run writes a manifest (commit, versions, host, times), the full
`pip freeze`, the configs it used and one log per step. `figures/make_figures.py` reads only
`results/paper/` and `figures/data/` and writes `figures/*.pdf` and the LaTeX tables
(`paper/tables/`). Instead of regenerating the data, the series and features of the
paper's run can be downloaded from Zenodo (see Data availability) into `data/paper/`.

## Layout

| Path | Role |
|---|---|
| `configs/` | Generation configs of the dataset (built by `src/make_configs.py`; the run checks it rebuilds them identically) |
| `src/make_configs.py`, `validate.py`, `generate.py` | The design from betise's list of combinations; checks of the configs against betise; generation |
| `src/topology.py`, `features.py` | TDA-90; the three feature families of each part, on the same series |
| `src/detectors.py`, `detectors_budget.py` | The detectors for every feature set and classifier; the equal-budget variant |
| `src/stats_main.py`, `stats_complementarity.py`, `stats_budget.py` | Tables and Nadeau–Bengio tests of the three comparisons (H1-H4, H5-H8, H9-H11) |
| `src/interpret.py`, `diagnose.py` | Feature-group ablation and set-level diagnosis (exploratory) |
| `experiments/run_all.sh` | The run, end to end |
| `experiments/exploratory/` | Classical tests as an exploratory reference (Python) and their independent R cross-check |
| `experiments/checks/` | Scripts and outputs behind individual statements of the paper (generator settings, GARCH persistence, TSFresh imputation, selection of the series of Figure 2) |
| `figures/` | `make_figures.py` and the input of Figure 2 (`figures/data/fig1_data.npz`) |
| `results/paper/` | Output of the paper's run: fold scores, out-of-fold predictions, tables, test statistics (`*/stats.txt`), run logs (`logs/`), manifest and environment |

## Data availability

The dataset is fully determined by `configs/`, betise 0.6.0 and the fixed seeds, and is
regenerated by the run. The generated series and extracted features of the paper's run are
archived on Zenodo: https://doi.org/10.5281/zenodo.23534965. The code is archived on Zenodo
through the GitHub release of this repository. The precomputed BeTiSe benchmark dataset
(Zenodo 10.5281/zenodo.18513505) is not used.
